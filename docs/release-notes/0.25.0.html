What's new in 0.25.0

Your library moves to a database

  • The first launch after this update performs a one-time migration. Mechanician shows its progress and reopens by itself when it finishes. On a large library this takes a few minutes; on a small one it is quick. It happens once, not on every launch.
  • Make sure you have free disk space first. The migration writes a full backup and a copy it can roll back to before it changes anything, so it needs roughly twice the size of your attachments. If there is not enough room it says so and does nothing.
  • Your previous library is kept, untouched, for a week afterwards. Once the new one has run for that long and proved itself, Mechanician moves the leftovers to the Trash and the space comes back. Nothing is released while anything about the new library is unproven.
  • A conversation Mechanician cannot read is carried across rather than left behind. Its exact file is preserved alongside the library, with a note recording what it was and what went wrong.

Mechanician starts faster

  • Opening the app is about twice as quick. On a 96-conversation library the sidebar became usable in 1.2 seconds instead of 2.5, and the conversation appeared in 2.9 seconds instead of 4.1.
  • Most of that came from one thing: launch was reading every finished subagent and workflow in the whole library, 104 MB of it, to answer one question about which conversations still had work running.
  • Settings, under Advanced, now reports how long the last few launches took and where the time went.

Connections

  • A server that cannot use browser sign-in now says so and offers a token. Signing in to one that does not support automatic registration used to fail with a Try Again button that could never succeed.
  • Tools appear right after you connect a server. They used to show up only sometimes, and asking again was what made the difference.
  • Reauthorizing while a message is already running now tells you it cannot reach that turn, instead of showing Connected with no tools available.

Windows and agents

  • Choosing a workspace acts on the window you opened the gallery from, rather than whichever window was last in front. It no longer pulls focus across Spaces or leaves two windows showing the same workspace.
  • The Agents panel section for failed work is now called Didn't finish and shows the agents that actually failed. One failed child used to bring its whole tree along, which made a single failure look like a widespread one.

Recovery

  • Check for Updates is always available, including when Mechanician cannot open your library. A build that will not start can now take the update that fixes it.
  • Mechanician repairs its own library folder permissions instead of refusing to open.
  • The message shown when a conversation's history could not be measured now says what happened to your conversation rather than describing the machinery.

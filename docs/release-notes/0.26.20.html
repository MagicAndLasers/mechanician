What's new in 0.26.20

This follow-up makes the one-time library update complete reliably and explains its result in plain language.

A real library-update flow

  • The update now has its own dedicated window. It no longer opens or renames a Workspaces window, and an old saved migration scene cannot reappear beside it.
  • A stopped update is visibly stopped: the animation, percentage, and elapsed timer go away, and the window offers Try Again. When the previous library is still provably safe, Use Previous Library for Now is available for that session.
  • A previous failed attempt can no longer suppress migration on later launches. Every still- unmigrated library retries, while interrupted committed work resumes safely.

Completion you can verify

  • Mechanician reports completion only after reopening the new library and matching its authority marker, database identity, schema, writer, and exact committed sequence.
  • After reopening, a one-time banner says Library update complete.
  • Settings → General now permanently shows the verified Library update status, so nobody needs Terminal commands or developer help to know which library is in use.

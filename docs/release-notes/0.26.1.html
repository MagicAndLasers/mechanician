What's new in 0.26.1

Summarizing earlier messages no longer looks like something went wrong. There is no migration in this update and nothing changes about your library.

Summarizing earlier messages reads as maintenance

  • When a conversation gets long, earlier messages are summarized so it can keep going. That is routine and it can happen many times in a long conversation. It was shown with a red alert icon and border, which made ordinary housekeeping look like a failure.
  • The note now says "Summarized earlier messages" and sits quietly in the transcript.
  • When summarizing does not work, the note is a caution rather than an alarm, and it tells you what happens next. Mechanician tries again on your next message, and in the one case where that will not help, because a single message is too large to summarize around, it says so and suggests what to do.
  • The internal error identifier is gone from the message. Text like Code: too_few_groups was shown as though it were something to act on. The detail still goes to the system log, where it can be used for diagnosis.

This update changes how summarizing is described, not how often it happens. If conversations are being summarized more than you would expect, that is being looked at separately.

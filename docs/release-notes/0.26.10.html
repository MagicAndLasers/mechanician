What's new in 0.26.10

Mechanician now tells you which configuration it is running. This affects organizations that use a managed configuration; everything else is unchanged.

You could not tell whether a published change had arrived

  • When your organization published a change to your configuration, nothing in the app said which version you actually had. If a newly added model did not appear, there was no way to tell whether the update had not arrived yet, or had arrived and something else was wrong.
  • The model picker now names the configuration and its revision underneath the list. On a managed setup that list is the configuration, so this answers the question in the place you notice it.
  • Settings, under Managed Configuration, now shows the revision this launch is using. If a newer one is already installed on the Mac, it says so and tells you to quit and reopen, because a configuration only takes effect on a fresh launch.
  • Those two cases look identical from the outside and need opposite responses: one is "restart", the other is "the update never reached this Mac". They are now distinguishable without opening a support ticket.

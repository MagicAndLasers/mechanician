What's new in 0.12.4

Extensions

  • MCP servers can ask you a question mid-task on Claude, not just Codex. A server that needs input it could not know in advance — a choice, a confirmation, a value — now shows you a form and waits for your answer. Previously every one of those requests was declined on the Claude side, so any extension that asks a question simply failed there with no explanation.

Providers

  • Claude on AWS Bedrock now asks your account which models it has rather than relying on a list built into the app. Which models a Bedrock account can use varies by account and region, so a fixed list is wrong for almost everyone — it offered names AWS has never heard of, and every turn failed. Your account is now the source of truth, and if it cannot be reached the app falls back to a usable list rather than an empty one.
  • Fixed: the Bedrock model names the app shipped with were wrong. They have been corrected to the identifiers AWS actually accepts, confirmed by running real requests.

Window

  • Work you can't see is now visible in the toolbar. Background processes the agent started, and conversations parked waiting for something to happen, are counted beside running turns. Waiting is shown separately from running, because a conversation waiting on a trigger is idle, not busy — clicking either takes you to where you can inspect, resume or stop it.
  • Fixed: the context and token readings no longer wrap onto two lines when the window is narrow. They stay on one line and the least important reading drops out first, instead of the most important one being cut in half.
  • Fixed: a waiting conversation no longer says "Waiting waiting for…".

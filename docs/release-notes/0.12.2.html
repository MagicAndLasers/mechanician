What's new in 0.12.2

Transcript

  • Assistant messages no longer break apart while streaming. Each streamed chunk carries its own identifier, and the transcript was treating every one as a new message — so a reply could persist as a row per chunk. Fenced code blocks were the visible casualty: the opening fence landed in its own row, so nothing parsed as code and snippets rendered as plain prose.
  • Copy button on code blocks. Hover any fenced block for a copy control in its top-right corner. It copies the block verbatim, so a long command can no longer be truncated by an imprecise selection.

Providers

  • Fixed: long API keys were silently truncated when saved. Keys were stored through a path that caps at 128 characters without reporting it, so an OpenAI project key (164 characters) was stored as a valid-looking prefix and then rejected by the provider as incorrect. Existing keys longer than that need re-entering.
  • Keys are now verified before they are saved. A key the provider rejects is refused while you are still looking at the field, rather than failing at the next turn. If the provider cannot be reached, the key is saved with a note instead of being blocked.

Scheduled & ambient work

  • Each scheduled task picks its own provider. Anthropic API, Claude on Vertex, or OpenAI API. Subscription providers are listed with the reason they cannot run unattended rather than being quietly absent.
  • Tasks say up front what they will not be able to do. The editor flags a task whose instructions expect a person — asking a question, waiting, taking a screenshot — and one that intends to change files while set to read-only access.
  • One unconnected provider no longer stops every other task from running.

Background work

  • Work an agent leaves running is now visible and stoppable in the Schedule window: poll loops, watchers and detached commands, each with a Stop button.
  • Waiting on lists conversations parked on a trigger, with resume and cancel.

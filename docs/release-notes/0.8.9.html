What's new in 0.8.9

  • Redesigned send & stop controls — a Magic & Lasers "beam" ring that charges when you type and ignites while the agent works, with a matching beam spinner throughout the app.
  • One Changes panel — the Git and Changes tabs merged into a single progressive view: it always shows what the agent touched, and reveals full git (branch, stage, commit, push, and real diffs) when the folder is a repository.
  • Scheduled & Ambient tasks, invested in — the calendar is always visible with one-click starters, a live "scheduler running" indicator, real run history, and clickable run notifications. You can now ask the agent to schedule work right in chat.
  • claude.ai connectors in-app — sign in and re-authorize Gmail, Google Calendar, and Google Drive without leaving Mechanician.
  • Reliable artifacts — large documents and dashboards no longer fail to render (fixes the "Stream closed" error).
  • Simpler surfaces — Extensions and Capabilities each live in one window now; the Discover tab refreshes automatically as you install or update apps.
  • A cleaner, faster app — removed the unreliable live-document attach and other unused surfaces.

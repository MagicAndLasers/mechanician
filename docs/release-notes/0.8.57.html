What's new in 0.8.57

  • Create workspaces from the workspace picker — the toolbar menu now includes New Workspace alongside quick switching and All Workspaces.
  • Add a folder whenever you need one — chat-only workspaces can gain a working folder later from the workspace menu, their All Workspaces card, or the workspace editor. Folder-backed workspaces can change folders through the same paths.
  • Safer folder changes — Mechanician preserves the workspace and its conversations, keeps open windows on the same conversation, rejects folders already assigned elsewhere, and waits for active work to stop before changing working directories.

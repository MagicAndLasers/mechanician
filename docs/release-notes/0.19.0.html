What's new in 0.19.0

Attachments the agent — and VoiceOver — can actually read

  • Attachments announce themselves while you write. Every attachment in the message box now reads as what it is — Attached file, Quarterly report.pdf, Mail message, Budget approval, Artifact, Sales chart, html — in the same words the transcript uses after you send. Previously they were silent while composing.
  • Dragging an artifact out gives it the right name. Artifacts dropped into the Finder or another app arrive as Badge.svg rather than Badge.svg.svg.

Drag and drop that finishes the job

  • The Files tab springs open. Hold an artifact over Files and the browser opens so you can drop it into a specific folder. This never worked before.
  • Drag a file from the browser to the Trash. The Trash used to refuse the drop entirely. Removal is recoverable, exactly as it is in the Finder.

Readable in Light Mode

  • Renaming a conversation is visible again. The inline title editor showed white text on a white background, so you could not see what you were typing.
  • The context meter reads at a glance. Its empty track was nearly as dark as the blue fill; the filled portion now stands clearly apart from the rest.
  • Tool activity labels are legible. Names on tool spans in the timeline sit on a deeper orange and are drawn in white rather than black.

Corrected behaviour

  • Delete no longer acts without a selection. In the conversation list, pressing Delete with nothing selected could act on the row you had last right-clicked.
  • Any private MCP registry works without a custom build. An organization's own catalog is now read by the general registry adapter and described entirely in its managed configuration, so supporting one no longer requires a new version of Mechanician. Existing registries keep working and migrate themselves.

What's new in 0.26.2

A failed summarization no longer costs you the conversation's session. There is no migration in this update and nothing changes about your library.

Conversations should restart far less often

  • When a conversation gets long, earlier messages are summarized so it can keep going. If that summarizing failed, Mechanician used to abandon the session and start a new one with your most recent messages. That is what showed as "Mechanician started a new session" and read as the conversation restarting.
  • Mechanician now retries in the same session first. Summarizing that fails once usually works on the retry, and when it does you see nothing at all: the conversation carries on.
  • Only the one failure known to cause a worse error afterwards still ends the turn. Every other kind is now handled the way Claude Code handles it, by carrying on.

If the retry also fails, the older behaviour still applies and Mechanician rebuilds the session, so nothing is lost that was previously kept.

For anyone helping to diagnose this

Summarizing is now logged in detail, including the reason for each failure and how it was resolved. If you have been asked for that output, quit Mechanician and run:

grep '\[context\]\[compaction\]' ~/Library/Application\ Support/Mechanician/logs/agentd-*.log

The files are per provider, so agentd-claude_vertex.log is the one for Claude on Google Vertex AI. They contain no message text.

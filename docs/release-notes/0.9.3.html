What's new in 0.9.3

  • Codex Ultra stays recoverable. Quiet turns are checked against Codex's authoritative state instead of being treated as stalled, and missing completion notifications are recovered without duplicating output.
  • More reliable stopping. If Codex reports that a turn is no longer active, Mechanician now reconciles the provider's thread state before deciding whether to finish or restart the lane.
  • Codex is self-contained. The app includes its pinned Codex App Server and code-mode runtime, so subscription users do not need a separate Codex installation.
  • Safer runtime boundaries. Provider processes, credentials, permissions, background work, and multi-window turn ownership have stronger isolation and failure handling.
  • Reproducible release builds. The signed app now records source and dependency provenance, ships a locked production runtime and license inventory, and verifies every artifact before publication.

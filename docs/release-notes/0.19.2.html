What's new in 0.19.2

The activity plot keeps up with the turn

  • Live plots no longer freeze while the ruler advances. The agent lanes and the token graph now repaint with the timeline instead of holding stale bars until something else redrew them.
  • A running turn's timeline only moves forward. It could previously jump ahead and then snap back, briefly shortening bars that were already drawn.

Faster first message

  • Opening a new conversation no longer discards a ready connection. A prepared provider process is reused for any conversation that needs the same setup, so the first message does not wait for one to be built from scratch.
  • Typing prepares the connection again after a pause. Applies to Claude on a subscription, an API key, Vertex, and Bedrock, and to Codex.

Fixes

  • Large files preview again in Changes. Selecting a big source file under Conversation History showed an empty pane instead of its contents.
  • A suggested follow-up is added to your message. Taking one used to replace whatever you had already typed, and left the cursor outside the box.

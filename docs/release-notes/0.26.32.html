What's new in 0.26.32

This Daily build is about correcting what Mechanician remembers. You can take back a statement you removed, remove several at once, see what the wiki holds twice, and see exactly what a conversation just added.

  • A statement you remove can be put back. When something has been removed, the Memory window offers it back, with the words you originally said behind it still attached. Removing was the one correction you could not undo.
  • Several statements can be removed together. A page now offers a list with tick boxes, so tidying a page is one decision rather than one conversation per statement. If any of them changed while the list was open, none are removed and the window says so, rather than removing the ones it still recognised.
  • The wiki says when it holds something twice. Where two statements say the same thing in different words, the Memory window offers both wordings and keeps whichever you choose, folding the other into it. Doing this previously meant asking the assistant, once per pair.
  • The "Added to memory" note in a conversation now opens, and shows the exact statements it wrote and the page each went to. It could always open; it had nothing to show.
  • Typing a request into "Add something to remember" no longer records it as a fact about you. The box records what you type, so a sentence like "please rewrite the summary for this page" became a preference. It now says so and keeps what you typed, and ordinary statements are unaffected.
  • A citation written as a pair, like [1, 2], is now one link you can follow rather than plain text.

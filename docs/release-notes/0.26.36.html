What's new in 0.26.36

Memory is easier to refresh, and Connections now shows the repeated conversation windows that make up a context instead of presenting one prompt as though it were the whole thing.

Connections shows what a context is made of

  • A context now groups similar four-turn conversation windows across the same workspace, including windows from different conversations. A card says how many independent windows it contains and shows a labelled four-turn example, so it no longer reads as one isolated prompt.
  • Only contexts with an actual learned memory relationship appear in the learned graph. Ordinary saved activity remains available as activity history rather than cluttering the relationship map with disconnected cards.
  • A conversation view shows only the statement evidence anchored in that conversation. The workspace view shows the complete shared context, including its other member windows.
  • When Connections rebuilds after the update, it recreates a disposable projection only. Your saved conversations and memory library are unchanged.

Refresh an existing profile

  • Memory now has a Refresh profile control even after a profile already exists. It reads newly changed conversations and clearly says when there is nothing new to add.
  • Routine refresh does not repeat public subject research or reread workspace documents. Those remain separate, explicit work.

The Memory inspector opens reliably

  • Choosing Memory in the inspector now opens the Memory overview, including when Connections was the last page shown.
  • Folder workspaces use the same saved inspector-tab configuration for what is displayed and what can be opened, so a visible Memory tab can no longer do nothing.

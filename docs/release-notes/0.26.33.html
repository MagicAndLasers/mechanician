What's new in 0.26.33

The memory wiki learns from more than conversation, and knows which workspace you are in when it goes looking. Building a profile now reads the documents your projects already carry, and looks up what the subjects on your pages actually are.

  • Build my profile reads your workspaces' own writing: READMEs, instruction files, and the documents inside a project's docs folder rather than only the ones sitting loose at the top of it. A project that has written no prose at all is described from its manifests instead, so a repository with no README can still say what it is built with and where it runs.
  • It also looks up the public subjects on your pages, so a page about a company or a product says what the thing is rather than only how you relate to it. Only a page title and what kind of thing it is ever leave your Mac, and everything found arrives as a suggestion you review. There is a switch for it in Settings, beside the other two memory switches.
  • The build says which account and model will run it, on the control that starts it.
  • Recall knows which workspace you are in. A conversation in a project now leans toward that project's page, so what comes back is about the work in front of you.
  • A fact said two ways no longer takes two of the slots a turn gets, and a message that asks nothing no longer has memory attached to it.
  • A subagent's memory reads and writes appear in the transcript with the subagent named, so delegated work is as visible as the main conversation's.
  • Statements and summaries render Markdown: emphasis, bold, code spans and links. File names with underscores are left alone.
  • Deleting a page asks first, says how many statements go with it, and can be undone. The recently-removed list can now be emptied for good, and what you emptied stays forgotten.
  • Merge all works on the pairs you are looking at, and says so when a merge cannot be made because a statement changed while you were reading.
  • Back and forward reach the pages you were reading, not only the index.
  • Share is in the file browser's menu, beside Reveal in Finder, and works on a whole selection.
  • Panels reopen where you left them.
  • Activity span labels are plain white with nothing drawn around the letters.
  • Updated to Claude Agent SDK 0.3.237 and Codex 0.148.0.

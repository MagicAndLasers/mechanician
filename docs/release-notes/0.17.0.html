What's new in 0.17.0

Artifacts move with the work

  • Move artifacts between workspaces. The artifact menu now offers Home, existing workspaces, and New Workspace; moving a conversation brings all of its artifacts with it.
  • Organize the library in bulk. The global Artifacts window gains native range and multiple selection with bulk Favorite, Move, and Delete, while the conversation inspector gains matching Favorite, Rename, and Delete actions.
  • Export rendered HTML as PDF. Save as PDF captures the complete artifact, including content below the preview viewport.

Attachments stay durable and editable

  • Attach any kind of file. Files are copied into the conversation and retain named, Quick Look-backed previews in both the composer and transcript.
  • Put attachments exactly where they belong. Drag previews around text and other attachments, with normal Undo and Redo support.
  • Copy complete drafts between conversations. Mixed selections now preserve text, images, files, and authored order while creating independent destination-owned copies.

Light Mode has the same visual care as Dark Mode

  • Appearance changes are coherent. Light, Dark, and System update every open window, toolbar, Settings surface, and custom layer together.
  • Color stays vivid and readable. Agent meters and timelines use all six Magic & Lasers rays, Git diffs and syntax use contrast-tested palettes, status labels remain legible, and the running composer shimmer is visible on white.

Activity history stays honest

  • History reduction is visible. When recovery sends a bounded portion of a conversation to the provider without native compaction, Trace now shows a distinct marker with omitted and shortened message counts.
  • Guidance stays inside the chart. Scrolling and zooming no longer lets a guidance flag paint through the frozen agent labels.

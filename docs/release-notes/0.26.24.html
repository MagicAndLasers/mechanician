What's new in 0.26.24

This Daily build makes multi-window workspace navigation clearer and establishes a safer path from Daily testing to Stable.

  • The File menu now has an explicit Open Workspace in New Window… command. It opens the workspace chooser without replacing your current conversation; choosing an already open workspace focuses it, while an unopened workspace gets its own window.
  • A tested Daily build can now be promoted to Stable using the exact same signed and notarized app artifacts—without rebuilding between Daily validation and Stable publication.
  • Publishing a Daily build leaves Stable download links untouched; Stable remains the default update channel.

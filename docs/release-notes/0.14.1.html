What's new in 0.14.1

Root work is visible and controllable

  • The conversation's root agent now has its own card. It sits below the whole-conversation summary and reports only the root turn's observed duration, token use, tool activity, and tool mix, so delegated work no longer inflates the root's figures.
  • Requested and provider-reported models are kept distinct. When Codex reports the model that actually answered, the root card retains that identity across model switches and relaunches without rewriting the model the user selected.
  • Root Stop is scoped to the root. The control reaches the bridge that owns the active or provisional root—even from a duplicate viewer—without stopping independent delegates. It remains available while assistant text is streaming.
  • Every agent Stop control now uses the same octagonal road-sign artwork. The composer, root, standalone-agent, workflow, and detail controls share one visual and accessibility treatment instead of mixing a stop sign with red squares.

Faster, quieter Codex startup

  • Codex thread prewarming now validates the complete turn configuration. Warm-state proofs include the exact model, workspace, permissions, process generation, and tool schema, so an incompatible prewarm is discarded rather than reused.
  • Skill inventory maintenance is quieter. Startup, workspace, plugin, and provider-change signals coalesce, and new refreshes are dispatched only while no root turn is active.
  • Codex Skills use the provider's authoritative, workspace-scoped inventory. System, user, repository, and enabled plugin skills retain the last valid result and reject stale responses from a previous workspace.
  • Provider compaction boundaries no longer fabricate a meaningless 0 → 0 token reading when Codex did not report before-and-after counts.

Recovery and reliability

  • Inconclusive Claude credential checks now offer Reconnect. The credential_unknown / status_unavailable failure remains honestly retryable, but its card also provides a forced fresh sign-in instead of leaving the user trapped behind repeated connection errors.
  • Claude's MCP guidance now treats the callable tool list as authoritative. It tells the model to prefer directly exposed mcp__… tools and to use discovery only when a discovery primitive is callable.
  • Agent-activity tooltips no longer retain transient Objective-C string owners. Native tooltip callbacks now stay with their views, fixing the AppKit pointer-authentication crash seen while hovering the activity panel.

A more recognizably Mechanician welcome

  • The Mechanician-titled new-conversation panel now pairs the app icon with the wordmark in the same display typeface used by the product site, with the licensed font bundled in every build.

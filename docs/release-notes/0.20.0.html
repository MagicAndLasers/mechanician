What's new in 0.20.0

A new way to add things to a message

  • The paperclip is now a plus. It opens a panel with your recent photos, a camera tile, and the rest of the sources beneath. Option-click still opens the file picker directly.
  • Recent photos, one click away. Click a thumbnail to attach it. Photos are opt-in: opening the panel never asks for anything.
  • Browse your library in a proper window. Pick several at once; they arrive in the order you chose them, with progress while each one is fetched.
  • Take a photo with your Mac's camera, or with an iPhone nearby acting as one.
  • Capture a screen area and attach it without leaving the conversation.
  • Import from iPhone or iPad now appears when you right-click the message box, which is also how you scan a document straight into a conversation.

Fixes

  • Attachments can be dragged to a new position again. Photos and file previews both.
  • Choosing several photos adds all of them. It previously added copies of one.
  • Photos are attached in a form the assistant can actually read.
  • Tool labels in the activity trace are legible on every colour.
  • Moving conversations moves everything you selected, not only the row you clicked.
  • The camera message points somewhere useful when a build cannot use the camera at all.

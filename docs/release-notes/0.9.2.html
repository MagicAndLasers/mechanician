What's new in 0.9.2

  • No separate Node install. Mechanician now carries a pinned, supported Node 24 LTS runtime inside the app.
  • Diffs without developer tools. The Changes panel can read Git status and staged, unstaged, untracked, and binary diffs without Xcode or Command Line Tools.
  • Clear Git setup. Stage, commit, and push actions explain when Command Line Tools or Xcode license acceptance is needed, while read-only diffs keep working.
  • Smaller runtime payload. Release packaging removes unused Intel/Windows native modules, source maps, declarations, tests, and package docs.

What's new in 0.26.42

Two fixes to the transcript: where it puts you while you are reading, and what it says about a command you declined.

The transcript stays where you left it

  • Reading back through a conversation no longer throws you to a much earlier part of it. When rows above you were added, removed or rebuilt, everything below them moved while your view stayed at the same place in the document, so you landed somewhere else entirely.
  • It happened periodically rather than rarely because a run of tool calls is regrouped as a turn goes along, which changes the rows above you during ordinary work.
  • One earlier row changing shape could move you more than 1500 points, which is several screens.
  • Following a live answer is unchanged. If you have not scrolled away, you are still carried to the bottom as it arrives.

A command you declined is not a command that failed

  • Declining a command left a red "1 failed" above it, and a row that said it ran. Nothing ran. It now reads "1 denied", with no red, and the row says "Denied" rather than claiming the command executed.
  • VoiceOver announced a declined call as "error". It now says "denied".
  • This is the same correction 0.26.41 made to what Memory records. Until now the record had stopped calling a refusal a failure while the screen still did.

What's new in 0.26.45

A fix for 0.26.44. That update reclaimed disk space correctly, but it rebuilt more of the search cache than it needed to, which made Mechanician re-read your conversations once to rebuild its memory profile. Upgrading from 0.26.44 or earlier now keeps that work.

Upgrading no longer re-reads your conversations

  • The record of which conversations memory has already read is now preserved through the update. In 0.26.44 it was discarded, so a profile refresh re-read everything once.
  • The oversized search index is still discarded and the space still reclaimed. That part worked and is unchanged.
  • Nothing was ever at risk: everything involved is rebuilt from your conversations and memory library, which are untouched.

What’s new in 0.11.17

  • Editable artifact references. Drag an artifact from either artifact panel into a chat to give the agent its current source and revise the same durable artifact. Dragging to Finder still exports a normal file.
  • A more natural composer breath. The chromatic activity outline now begins at one midpoint, opens in both directions around the command box, reunites at the opposite midpoint, and reverses in one synchronized inhale-and-exhale cycle.

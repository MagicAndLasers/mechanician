What's new in 0.16.3

Conversation titles make tabs useful

  • Native tabs now show conversation names. The workspace remains the window title, while each tab follows its selected conversation and updates after a rename or an automatically generated title.
  • Generated titles no longer compete with the first answer. Apple Intelligence title generation begins only after the response finishes, and malformed labels, Markdown, code, multiline output, and refusal text are filtered before a title is saved.
  • Existing titles can be repaired safely. Regenerate Title replaces an old malformed name on demand, while delayed generation never overwrites a title you chose.

Home is one shortcut away

  • Press ⇧⌘H to go Home from any workspace. Mechanician focuses an existing Home window when possible and otherwise reuses the current window, so a tangent is quick to capture without creating duplicate windows.

Builds coordinate per project

  • Unrelated project builds can run concurrently. Builds for the same project queue in order instead of reporting a false failure, while separate build roots no longer block one another.

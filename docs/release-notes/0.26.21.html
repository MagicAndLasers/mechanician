What's new in 0.26.21

This update fixes a library-migration refusal that could repeat forever after Mechanician had already safely inventoried an old malformed trash entry.

  • The rollback-capture step now uses the same per-source safety proof as the migration itself, instead of rejecting every accounted trash issue a second time.
  • Malformed or unrecognized trash entries remain untouched in the protected library folder; they no longer prevent healthy conversations from completing migration.
  • Opening 0.26.21 automatically retries the existing migration. No Terminal commands or manual cleanup are required.

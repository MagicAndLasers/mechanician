What's new in 0.11.13

  • Keeps Vertex AI Claude running when a corporate proxy returns a malformed authentication response, and shows the real runtime exit code when a provider process does stop.
  • Repairs Claude sessions whose required Ask control was advertised but no longer mounted, automatically refreshing the session on the next message.
  • Activates the workspace for Finder and Dock drops and preserves visible previews for image attachments.
  • Keeps New Window as a standalone window on macOS Tahoe, including while another workspace is full screen.
  • Shows the provider-reported context-window size for Claude aliases and 1M model variants instead of falling back to 200k.

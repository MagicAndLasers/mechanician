What's new in 0.16.0

Install Claude plugins from archive registries

  • Add HTTPS archive registries as Claude marketplaces. Organization-managed and user-added catalogs appear alongside native Claude marketplaces, with each plugin's capabilities, provenance, and context cost visible before installation.
  • Manage archive plugins in the Claude Plugins browser. Installed plugins survive relaunch and can be enabled, disabled, updated, or uninstalled like native marketplace plugins.
  • Downloads are installed defensively. Mechanician bounds downloads and expanded archives, verifies declared SHA-256 digests, rejects unsafe paths and mismatched manifests, and publishes verified content atomically. Plugins can contain executable hooks and MCP servers, so review their contents and install only from sources you trust.

Recover oversized Claude conversations

  • Large conversations recover instead of getting stuck after compaction fails. When replay is still safe, Mechanician retries once in a fresh Claude session with the newest durable history that fits and explains when older context was reduced.
  • The current prompt is never silently truncated. If the prompt itself is too large, clear Edit Prompt and Start Fresh actions help you shorten it or move it without pretending that reconnecting will solve a context limit.
  • Pasted images stay attached during recovery. App-owned images are copied safely when a rejected draft moves to a fresh conversation, while unavailable attachments are called out explicitly.

MCP sign-in failures explain the next step

  • Authorization errors are stage-aware and actionable. The Extensions window distinguishes retryable network or VPN failures, endpoint configuration problems, denied access, token exchange failures, and servers that need a manually configured token.
  • Cancel really cancels. Pending browser state clears immediately, and a late result from an older attempt cannot overwrite a newer sign-in.
  • Diagnostics remain privacy-safe. Raw OAuth responses, URLs, credentials, and tokens stay out of the app-facing failure details.

More reliable extension catalogs

  • Catalog responses are bounded and validated as JSON. Oversized feeds, malformed JSON, and proxy or login pages now produce a useful error instead of being parsed as a catalog.
  • Managed Google-authenticated catalogs offer recovery. Expired or denied Google identity is identified as an account issue with Reconnect Google and Retry Catalog actions in the Claude plugin catalog.

Clearer help

  • In-app help is organized around tasks. The internal-sounding Composer topic is now Writing a Message, and the workspace guide reflects the current Workspace menu and instruction entry points.

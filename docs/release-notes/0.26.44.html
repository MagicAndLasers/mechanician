What's new in 0.26.44

Mechanician now uses far less disk. On a library of about a hundred conversations this update returns roughly two thirds of the space the app was holding, without deleting a single message.

A much smaller search index

  • Long tool output is no longer indexed in full. A single command could put a megabyte of output into the search index, so the index grew with how much your tools printed rather than with how much you had said. It is now bounded per message.
  • Your own messages and Mechanician's answers are still indexed generously. Only bulk output, such as a long file listing or build log, is shortened for search.
  • Search will no longer match text buried deep inside a very large tool output. The complete text is still in the conversation itself, and searching for the command, the file path, or anything you wrote works exactly as before.
  • The index is rebuilt in the background after this update, so conversation search may return fewer results for a short while on the first launch.

Conversations take less room

  • Large tool results are now stored compressed. Nothing is removed and nothing is summarised; the same text is simply kept in less space, and it is decompressed whenever it is read.
  • Existing conversations are compressed as they are next written. Your messages, answers and everything visible in a transcript are unchanged.

Space is actually returned

  • Databases do not normally shrink when their contents do. This update compacts the search cache once, on the first launch, so the space really comes back to your disk rather than being held for later.
  • Your conversations, memory library and workspace settings are untouched by that step, and your memory profile is not re-read.

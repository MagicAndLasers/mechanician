What's new in 0.24.0

Conversations stay where you put them

  • Mechanician reliably returns to the conversation you left open. Provider warm-up can no longer replace it with a blank conversation, and the first sidebar click made during launch is retained instead of ignored.
  • Pin, Unpin, Mark Read, and Mark Unread work again from the Conversation panel, including pinned-row ordering.
  • The composer no longer shifts or bounces the transcript when the first character is typed.

See agent work when it begins

  • The Agents panel opens when a workflow or subagent first starts. Live workflow children appear without duplicate mirror rows, so the panel reflects the work actually in flight.
  • Forked and replayed conversations disclose their local provenance and any replay limitations instead of silently implying an exact continuation.

Large libraries use less of the foreground

  • After its disposable summary cache is populated, the Conversation sidebar can paint while recovery continues off the main thread, and full-text search now finds terms inside tool output.
  • Workspace moves, exports, and related multi-conversation work hydrate off the main thread instead of blocking the interface.
  • The opening state now uses Mechanician's accessible three-dot mark instead of a generic large progress indicator.

Durability and storage diagnostics

  • Your prompt is persisted before the provider receives it. A crash during turn startup restores it visibly and paused rather than losing or silently resending it.
  • Conversation and Workspace save failures now remain visible, retry safely, and never update search indexes before the authoritative write succeeds.
  • The in-progress library.db shadow migration remains isolated to signed dogfood builds. Public builds do not create or reconcile that shadow library before it provides a product read path.

Experimental Conversation Records

  • File-menu tools can export and inspect a provisional .convrec snapshot. Inspection is inert and read-only; importing or resuming work from a record is not supported yet.

Known limitation

  • Initial Conversation readiness still performs complete legacy-library recovery. This release makes that wait accurate and visible; selected-first startup acceleration is the next performance checkpoint.

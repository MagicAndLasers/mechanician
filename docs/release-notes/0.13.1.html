What's new in 0.13.1

The Activity panel

  • New: see what this conversation's own agent is doing. The Agents tab tracked delegated agents only, so a turn that delegated nothing showed an empty panel while the conversation's own agent did all the work. A summary strip now sits above the list showing its current step, what it is acting on, how long it has been there, how much it has processed, and which tools it has used.
  • Fixed: the Usage charts now have labelled axes. Both charts showed a single number in a corner with no unit and nothing to measure against, and the context chart had no time axis at all — you could watch context climb but not see when. Both now carry value and elapsed-time labels.
  • Fixed: a bar's height finally means something. The token chart's header states the span each bar covers (for example "tokens per 491ms"), so a bar can be read as a rate and compared against another turn instead of only against its neighbours.
  • Fixed: context usage was invisible on a large window. The context chart was scaled to the whole context window, so a conversation using a small share of a large one drew a flat line along the bottom and its shape could not be seen at all. It now scales to the context actually measured; the gauge in the header still shows how close you are to the limit.

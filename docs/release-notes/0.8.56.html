What's new in 0.8.56

  • A focused Connections window — apps and remote services now live together, while local MCP processes are grouped under On This Mac. Status, sign-in, enablement, editing, and removal remain available without exposing provider implementation taxonomy.
  • A smaller, safer add flow — connect GitHub, Notion, Linear, or Sentry from a curated list, or configure any MCP server manually. GitHub now asks for its required token header instead of attempting unsupported browser OAuth.
  • Clearer product boundaries — provider packages move behind Advanced, public registry and marketplace browsing leave the shipping workflow, and saved capabilities plus App Actions return to a separate Mac Automation window.
  • Correct Codex conversation continuity — resumed Codex threads receive only the new message instead of a duplicate copy of the full transcript. Durable history is replayed only when Mechanician intentionally creates a replacement thread.
  • Fresh Changes state — the visible Changes panel now refreshes quietly while repository state changes, without clearing the current snapshot or selection.

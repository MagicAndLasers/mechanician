What's new in 0.26.0

Search now puts the best match first and shows you the text that matched. There is no migration in this update and nothing changes about your library.

Search ranks by relevance

  • Results are ordered by how well they match, not by what happens to be pinned or recent. A conversation that mentions your term once no longer sits above the one the term is really about.
  • A title match comes first, because that is the most direct answer to what you typed. Pinned and Previous stay as separate sections, so the list keeps its shape.

Each result shows the text that matched

  • The row shows the matching passage instead of the conversation's newest message. Search reads tool output as well as what you and the agent wrote, so a conversation could match on a command result from weeks ago while the row showed something unrelated. Now you can see why it is in the list.
  • When a match sits deep inside a very large result, Mechanician shows no excerpt rather than showing you the beginning of something else and implying that is the match.

Plainer wording, and error messages you can act on

  • Nine places that showed raw text from the storage engine or the web renderer now say what happened and what to do about it. Saving a conversation, exporting a PDF, creating an instructions file, and writing a diagnostics file all report in ordinary language. The technical detail still goes to the system log for diagnosis.
  • "Chat" is gone from the interface. Conversations are called conversations, and a workspace without a folder is described as exactly that.
  • Punctuation across roughly 150 messages, labels and tooltips is plainer.

One more folder permission that could have stopped Mechanician

  • The rule that keeps your library readable only by you was written in four separate places. Two of them were taught to correct the folder after a refusal stranded people at launch in 0.24.2 and 0.25.3. The remaining copies now do the same.
  • When Mechanician does decline, because a folder it does not own is open to other accounts on the Mac, it now names the folder and the permissions it found instead of restating the rule.

Groundwork for other languages

  • Mechanician now carries a string catalogue, so translating it later is a translation job rather than an engineering one. No new language ships in this update and nothing looks different.

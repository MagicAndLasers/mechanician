What's new in 0.8.55

  • Provider recovery that stays out of your way — Codex now restarts its App Server after a failure without treating a healthy ChatGPT login as disconnected. Stop escalates when a provider does not respond, and a clear recovery action replaces an endless spinner.
  • Honest Guide Current Turn delivery — guidance remains visible while it is delivered, and a rejected or timed-out steer shows its reason before being sent once as the next message.
  • Safer crash and relaunch behavior — restored queues wait for confirmation instead of silently starting work, stale activity is healed, daemon shutdown is bounded, and provider diagnostics are retained in rotating logs.
  • Reconnect directly from the model picker — configured but disconnected providers keep their last-known model list visible as recovery information, with an inline Reconnect action.
  • Context-meter parity — context usage now persists across conversation switches and relaunches for Claude, Codex, and direct API conversations.
  • More stable conversation controls — changing effort or models no longer destabilizes an open popover, and the utility controls now share one compact native toolbar rail.
  • Deeper Codex integration — connected Codex accounts gain native change review, more truthful child-agent status and metrics, and reliable final agent reconciliation.
  • Sharper workspace feedback — the Changes panel refreshes from agent and terminal activity, conversation commit markers require real Git evidence, and Markdown tables render natively.

What's new in 0.26.23

You can now choose whether Mechanician offers only stable releases or also offers daily builds.

  • Stable is the recommended default for existing users, new installations, and any missing or unrecognized preference.
  • Daily Builds is an explicit opt-in under Settings > Updates. It includes early daily builds as well as every stable release.
  • Daily updates are clearly labeled before installation. Stable never downgrades the installed app; future checks wait for a newer stable release.
  • Daily publication preserves the stable download links and uses the same signed, notarized, monotonically versioned update feed.

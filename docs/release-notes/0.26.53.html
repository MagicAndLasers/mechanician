What's new in 0.26.53

This Stable prevents a rare Agents-panel hang from saturating the Mac's CPU during large, agent-heavy workflows.

  • Agent presentation now pauses while macOS is tracking a menu or drag, then catches up once when normal interaction resumes.
  • Large failed workflows no longer repeatedly sort and remeasure every agent card for each activity update. Updates recalculate only the affected rows.
  • The activity timeline reuses its processed ledger while drawing, and leaving Mechanician ends any stranded menu-tracking session.

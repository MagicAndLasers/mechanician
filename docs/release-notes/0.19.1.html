What's new in 0.19.1

Faster, steadier Claude turns

  • Managed Vertex connections no longer stall on an unsupported context check. A healthy provider session is retained between turns instead of waiting and rebuilding.
  • Safe chained turns avoid an unnecessary round trip. Supported Claude connections can reuse recent provider context evidence when the session is comfortably below its limit. Uncertain, changed, or near-limit contexts still take the authoritative path.

Agent activity that stays truthful as it moves

  • Tool colors now mean the same thing everywhere. A tool keeps the color it has in the agent card's tool mix when it appears in Activity Trace. The key shows the complete palette and explains it to VoiceOver.
  • The live token graph no longer slides backward. Completed activity stays anchored while a turn grows, and older bars merge predictably only when the time scale changes.

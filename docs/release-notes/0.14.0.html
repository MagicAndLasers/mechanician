What's new in 0.14.0

See the whole agent conversation

  • The conversation summary now includes every agent. Delegated work is folded into the active or latest turn, aliases are reconciled, and its token totals use the same arithmetic as the Activity headline. A parent that launches four agents no longer looks like it did nothing but call Agent four times.
  • Shell work is named for the program that actually ran. Activity traces and cards show names such as rg, git, sed, find, and swift instead of a wall of Bash. Labels are drawn only when they fit inside their spans, eliminating collisions while preserving full hover and accessibility details.
  • The completed summary stays put. Finishing a turn no longer removes the conversation strip, and narrow layouts reflow or abbreviate metrics instead of silently clipping them.

AppKit agent cards reach feature parity

  • Parent and child agents are visibly related. Nested agents are indented from their parent in both cards and the trace, including lifecycle events that arrive before their hierarchy metadata.
  • Cards show the model that actually ran when the provider reports it. Claude and Codex children can carry a different model from their parent; Mechanician displays that provider-authored model without guessing when it is absent.
  • The AppKit panel now carries the complete working state. It uses Mechanician's spinner, current work and stall presentation, metrics, summaries, errors, tool composition, workflow progress, output-file actions, warnings, disclosure, and complete accessibility descriptions. Background shell tasks no longer appear as phantom agents.

Stop, redirect, and recover stuck work

  • A provider failure can no longer strand delegated work. Terminal errors reconcile subagents, workflows, and workflow children, stamp their end times, and close their activity lanes. A normal successful parent completion still allows intentional background delegates to finish.
  • Stop remains available while any conversation work is active. It can stop a root turn, a provisional start, or delegate-only work even when no active root route remains. Recovery is scoped to the affected conversation and terminal state cannot be resurrected by delayed provider events.
  • Queued prompts and in-flight guidance can change direction. Edit a queued prompt, cancel pending guidance, or upgrade either one to Stop and Redirect. Provisional guidance remains visible before provider acknowledgement, and an unresponsive provider lane cannot repeatedly resubmit the same recovered redirect.
  • Provider switching explains and resolves blockers. Active delegated work presents an actionable Stop control, duplicate transcript warnings are suppressed, and a terminal usage-limit recovery frees the picker immediately.

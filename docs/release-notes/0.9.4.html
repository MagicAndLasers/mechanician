What's new in 0.9.4

  • Fast, responsive launches. Mechanician no longer waits on the main thread while macOS validates bundled runtimes or while launchd refreshes background scheduling.
  • Safer background startup. Provider and ambient processes now launch asynchronously, and a window close, quit, or settings change safely cancels a launch that is still pending.
  • Less scheduler churn. The background agent refreshes only after the app build changes instead of being torn down and recreated on every launch.

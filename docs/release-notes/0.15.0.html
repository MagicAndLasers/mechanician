What's new in 0.15.0

Standing instructions for each workspace

  • Every workspace can carry its own standing instructions. Set them once and each conversation in that workspace starts with them, so the context you would otherwise retype belongs to the workspace instead of to a single conversation.
  • Home gets the same treatment. Loose conversations that live outside any folder can hold standing instructions too, rather than being the one place without them.
  • Scheduled runs read the current instructions. The background scheduler can outlive the app, so it re-reads the instructions immediately before each run instead of acting on a copy that may be days old.

The activity timeline tells the truth about compaction

  • Compaction is drawn for the time it actually took. It used to appear as a few-pixel stub at the moment it began, with the completion flag stranded far to the right and ordinary model work drawn across the gap between them. A 31-second compaction is now a 31-second block that ends exactly on its completion marker.
  • The block spans the whole lane. Nothing else runs while a conversation is compacting, so it reads as the agent's whole state rather than a minor sub-activity, and it shows the before and after context size when the provider reports them.

Agent cards stop cutting off what matters

  • Model names are no longer clipped. The pills sat in a fixed share of the header, so they were trimmed mid-word while empty space sat beside a short title — and because everything shrank in proportion, the widest pill lost the most, which was always the model version. The route and agent type now give up room first.
  • Start times are readable again. Timestamps were being trimmed from the left even with room to spare, turning 11:21 AM into …:21 AM.

Pinned conversations look pinned

  • The pin marker now uses the app's own blue instead of the same grey as every other glyph in the row, so a pinned conversation is identifiable at a glance.
  • Pin and Unpin swipe actions wear the Magic & Lasers violet in place of the dark amber that read as mustard, and stay clearly distinct from the blue Mark Unread action beside them.

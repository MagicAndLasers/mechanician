What's new in 0.26.51

This Daily makes long, agent-heavy conversations steadier: background workflows finish reliably, the composer stays responsive while they run, and the transcript no longer shifts or clips its message actions.

Reliable background work

  • Claude workflows now keep their permission context until every background agent has finished. A root answer can no longer end the session underneath its children and leave an apparently successful workflow with an empty result.
  • Turns waiting on a visible permission card are no longer reported as stalled.
  • Harness-only activity left by an interrupted launch is closed during restart instead of leaving the activity bar running forever.

A calmer transcript and composer

  • Transcript rows are measured before they reach the viewport, substantially reducing the independent card movement that made scrolling through long conversations disorienting.
  • Copy, Retry and Fork remain fully visible after a response finishes and after a cold conversation reload.
  • Typing and correcting a message stays responsive while tasks are active. Task publications no longer repeatedly rebuild the editor, the full transcript, or the Agents accessibility tree.

Provider improvements

  • Agents inherit the same usable command path as the person, including a working npm.
  • Images generated by Codex now appear directly in the transcript.

What's new in 0.16.2

Agent cards and Activity stay in sync

  • Claude background agents remain active until they actually finish. An asynchronous launch acknowledgement no longer moves a still-running agent into Completed.
  • The profiler trace follows the same terminal lifecycle as the agent cards. Delayed or out-of-order provider updates can no longer draw work after an agent has ended.

Magic & Lasers color throughout

  • Agent meters now use the six-color Magic & Lasers spectrum. The palette is clearer, more cohesive, and tuned for both light and dark appearances.
  • The composer border, text cursor, and working spinners share that spectrum. Activity feels connected across the app without changing what each status means.
